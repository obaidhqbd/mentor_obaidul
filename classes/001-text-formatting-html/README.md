# Class 001 — Text Formatting in HTML

## Files
- `class.json` — class metadata
- `index.html` — lesson/project source
- `style.css` — project styling
- `script.js` — small interactive challenge
- `assets/` — place class-specific media/assets here

## Suggested student task
Change the heading, add more formatted text, and experiment with:
`strong`, `em`, `mark`, `small`, `del`, `ins`, `sub`, `sup`, `code`, and `blockquote`.
